# Jixel v0.1 — Implementation Plan

Spec: [`../specs/2026-10-17-jixel-design.md`](../specs/2026-10-17-jixel-design.md)

Each phase ends with green tests and a commit.

## Phase 1 — Rust workspace & JXL codec
1. `core/Cargo.toml` workspace with `jixel-core`, `jixel-cli`.
2. `jixel-core::image_buf` — `Raster` type (width, height, channels, bit depth,
   interleaved `u8`/`u16`/`f32` samples, optional ICC), conversions to/from `image::DynamicImage`.
3. `codec::jxl::encode` — safe wrapper over `jpegxl-sys`:
   distance/quality, lossless, effort, progressive, group order + centre,
   ICC, metadata boxes, multi-frame (layers + animation), JPEG recompression.
4. `codec::jxl::decode` — pixels (u8/u16/f32), ICC, boxes, frames,
   JPEG reconstruction, partial (progressive) decode.
5. Tests: lossless round-trip, JPEG bit-exact reconstruction, layered decode composites.

## Phase 2 — Other formats & operations
1. `codec::raster` — decode any supported format, encode PNG/JPEG/WebP/AVIF/GIF/TIFF/BMP/QOI/ICO/TGA/PNM.
2. `convert` — single entry point `convert(input bytes, ConvertOptions) -> Output`.
3. `ops::resize`, `ops::crop`, `ops::tiles` (+ DZI), `ops::subject`, `ops::background` (tract + U²-Netp).
4. `analyze::inspect`, `analyze::compare` (SSIMULACRA2, format battle), `analyze::progressive`.
5. `web::export` — widths, fallbacks, manifest, snippets, server configs.

## Phase 3 — CLI
`jixel convert | web | info | compare | crop | tiles | rmbg | reconstruct | preview`.

## Phase 4 — Flutter app
1. `flutter create app` (all platforms), add flutter_rust_bridge, `app/rust` bridge crate.
2. Theme, adaptive shell, l10n (en/it).
3. Screens: Home, Convert (batch queue), Web Export, Studio (compare slider,
   subject focus, crop/tiles, background removal, progressive preview, format battle),
   Inspect, Settings.
4. Widget tests; macOS build verified locally.

## Phase 5 — Docs, CI, repo
README (en/it), docs/ (en/it): JPEG XL guide, user guide, web delivery, CLI,
architecture, building, contributing; ADRs; GitHub Actions; private repo push.
